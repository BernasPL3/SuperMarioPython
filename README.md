# Super Mario Python

A platformer game inspired by classic Mario-style gameplay.

Built 100% with Python and Pygame.

---

## Features

- Platform gameplay
- Jump physics
- Enemies
- Coins
- Multiple platforms
- Lives system
- Win and Game Over screens
- Smooth movement
- Retro style

---

## Requirements

- Python 3.11+
- Pygame

Install dependencies:

```bash
pip install -r requirements.txt
